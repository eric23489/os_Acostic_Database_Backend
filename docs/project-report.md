# 洋聲聲學資料庫 — 專案報告

**報告日期**：2026 年 3 月
**目前版本**：Phase 7 完成
**測試覆蓋率**：85%

---

## 一、系統簡介

洋聲聲學資料庫是一套專為海洋聲學研究人員設計的水下錄音資料管理平台。

研究團隊出海佈放水下錄音儀器後，往往需要整理大量的錄音檔案、佈放地點與設備紀錄。本系統提供統一的數位管理介面，讓研究人員可以遠端存取資料、大量上傳音檔，並快速查詢每次佈放的時間、地點與設備資訊。

---

## 二、系統能做什麼

### 帳號管理

| 功能 | 說明 |
|------|------|
| 登入 | 以 Email 帳號登入，或直接使用 Google 帳號一鍵登入 |
| 密碼重設 | 忘記密碼時，透過 Email 收取重設連結，自行更新密碼 |
| 帳號綁定 | 可將現有帳號與 Google 帳號連結，方便日後快速登入 |

### 研究專案管理

| 功能 | 說明 |
|------|------|
| 建立專案 | 為每項研究計畫建立獨立的管理空間 |
| 編輯與刪除 | 可修改專案資訊，或將專案移入「已封存」狀態 |
| 誤刪還原 | 刪除的專案不會立即消失，管理員可在誤操作後還原 |
| 永久刪除 | 確認不再需要時，由管理員執行永久刪除，釋放儲存空間 |

### 佈放點位管理

| 功能 | 說明 |
|------|------|
| 記錄位置 | 以地理座標（經緯度）記錄每個佈放點的精確位置 |
| 查詢 | 可依地理區域或名稱搜尋佈放點 |
| 部署計數 | 每個點位會自動統計曾執行過多少次佈放 |

### 部署記錄

| 功能 | 說明 |
|------|------|
| 記錄佈放 | 紀錄每次出海佈放的時間、使用的設備型號 |
| 記錄回收 | 紀錄回收時間，形成完整的佈放週期 |
| 查詢歷史 | 可追溯每台設備在哪個點位、哪個時間段運作 |

### 音檔管理

| 功能 | 說明 |
|------|------|
| 大量上傳 | 一次上傳數十至數百個音檔，系統自動排程逐一處理 |
| 斷點續傳 | 網路中斷或程式關閉後，重新連線可從中斷處繼續上傳，不需重頭來過 |
| 自動解析 | 上傳完成後，系統自動讀取每個音檔的錄音長度、採樣率、聲道數等技術資訊 |
| 進度查詢 | 可隨時查看批量上傳任務的進度與各檔案狀態 |
| 取消任務 | 上傳中若需取消，系統會同步清除未完成的暫存檔案 |

### 系統健康監控

| 功能 | 說明 |
|------|------|
| 自動回報 | 系統提供健康檢查介面，可即時確認資料庫與檔案儲存空間（雲端硬碟）的連線狀態 |
| 外部整合 | 可與監控工具（如 Uptime Robot）串接，在服務異常時自動發送通知 |

## 三、開發歷程

| 階段 | 時間 | 主要成果 |
|------|------|---------|
| Phase 1–2 | 2025 年 1 月 | 系統基礎建設完成；帳號登入與註冊；研究專案、佈放點位、部署記錄、音檔的基本新增、修改、查詢功能 |
| Phase 3 | 2025 年 2 月 | 安全刪除機制上線：刪除的資料不立即消失（可還原），永久刪除需管理員授權 |
| Phase 4–5 | 2026 年 2 月 | Google 帳號登入、忘記密碼功能；系統測試覆蓋率從 75% 提升至 85% |
| Phase 6 | 2026 年 2–3 月 | 大量音檔批量上傳、斷點續傳、音檔資訊自動解析 |
| Phase 7 | 2026 年 3 月 | 統一錯誤訊息格式，前後端溝通更清晰；系統健康監控端點 |

## 四、後續計畫

### 近期（下一階段）

| 功能 | 說明 |
|------|------|
| 批量音檔下載 | 支援一次下載多個音檔，方便研究人員進行後續分析 |
| 即時資料推送 | 資料有異動時（如新增音檔、狀態更新），系統自動通知前端，無需手動重新整理頁面 |
| 輸入驗證強化 | 全面審查各功能的資料輸入規則，提升系統穩定性 |
| 佈放次數顯示 | 每個佈放點位自動顯示歷史佈放次數，方便評估地點使用情況 |
| 儀器功能擴充 | 支援更多儀器類型（如釋放儀）；每台儀器可上傳設備照片；顯示儀器目前是否正在水下佈放中；提供儀器整體使用統計 |
| 部署人員記錄 | Deployment 新增佈放人員與回收人員欄位，完善每次出海的人員紀錄 |

### 中期

| 功能 | 說明 |
|------|------|
| 統計報表 | 提供各研究專案的音檔數量、佈放次數等彙整數據 |
| 時間範圍查詢 | 各資料查詢功能支援依日期區間篩選 |
| 即時通知 | 系統事件（如上傳完成、異常）以 Email 或 Line 通知相關人員 |
| 暫存檔自動清理 | 未完成的上傳任務超過設定天數後，系統自動清除暫存檔，避免佔用儲存空間 |
| 音檔串流播放 | 直接在系統內播放音檔，無需先下載 |
| 分級權限管理 | 細分使用者角色，不同角色只能存取對應範圍的資料 |
| 登入憑證自動更新 | 登入憑證到期時系統自動在背景更新，使用者不會因憑證過期而被中斷 |

### 長期

| 功能 | 說明 |
|------|------|
| 快取加速 | 常用查詢結果暫存於記憶體，減少等待時間 |
| 查詢優化 | 針對資料量大的查詢進行效能調整 |
| 操作稽核日誌 | 記錄所有資料修改操作，方便追溯與稽核 |
| QR Code 快速建立佈放記錄 | 出海時掃描 QR Code 自動帶入設備資訊，快速建立佈放草稿 |
| 歷史資料冷儲存 | 較舊的資料自動移至低成本儲存層，降低長期儲存費用 |

### 系統上線準備

| 項目 | 說明 |
|------|------|
| 流量管理 | 設定反向代理，統一對外服務入口並提升安全性 |
| 網域設定 | 綁定正式網域，提供穩定的對外存取位址 |
| 系統監控 | 建立儀表板，即時查看服務健康狀態、API 回應速度、儲存空間使用率 |
| 速率限制 | 防止單一來源短時間內大量請求，保護系統穩定性 |
