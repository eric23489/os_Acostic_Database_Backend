審查「$ARGUMENTS」的安全性：

**權限控制:**
- 需要什麼權限層級？
- 是否正確驗證資源所有權？
- Admin 專屬操作是否有保護？

**輸入驗證:**
- 所有輸入都有驗證嗎？
- 是否防止 SQL Injection？
- 是否防止 Path Traversal？

**資料外洩風險:**
- 回傳資料是否過多？
- 錯誤訊息是否洩露資訊？
- 日誌是否記錄敏感資料？

**OWASP Top 10:**
- 注入攻擊
- 身份驗證失敗
- 敏感資料暴露
- 存取控制失效

輸出：安全檢查清單 + 風險等級
